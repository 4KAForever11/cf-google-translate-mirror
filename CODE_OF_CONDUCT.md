# Contributor Covenant Code of Conduct / 贡献者行为准则

## Our Pledge / 我们的承诺

We pledge to make participation in this project a harassment-free experience for everyone. / 我们承诺让参与本项目的每个人都不受骚扰。

## Our Standards / 行为标准

Examples of positive behavior: / 正面行为示例：

- Being respectful and welcoming / 尊重并欢迎他人
- Accepting constructive criticism gracefully / 优雅地接受建设性批评
- Focusing on what is best for the community / 以社区利益为重

Examples of unacceptable behavior: / 不可接受的行为：

- Trolling, insults, or personal attacks / 挑衅、侮辱或人身攻击
- Publishing others' private information / 泄露他人隐私
- Other conduct inappropriate in a professional setting / 其他在专业场合不当的行为

## Enforcement / 执行

Instances of abusive behavior may be reported to the maintainer via GitHub. All complaints will be reviewed and investigated promptly and fairly. / 滥用行为可通过 GitHub 向维护者报告，所有投诉将得到及时、公正的处理。
